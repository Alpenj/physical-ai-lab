# Physical AI Lab

Personal Physical AI learning logs written while attending a government-funded Physical AI course. DAPIER is my own repository for organizing course notes and hands-on practice, not a repository that I am learning from.

The home page is an archive-style blog: profile, categories, recent posts, related Shorts, and the study path appear before the individual articles. Each article separates what was understood, what was inspected, what remains unverified, and what will be tested next.

## Local preview

Open `index.html` in a browser, or serve the folder with any static file server. Individual articles live under `articles/`.

## Publishing

This folder is prepared for the `Alpenj/physical-ai-lab` GitHub Pages repository. It contains no private Notion URLs, local machine paths, credentials, raw transcripts, or unverified experiment claims.
